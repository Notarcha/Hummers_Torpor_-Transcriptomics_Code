# Hummers_Torpor_Transcriptomics_Code
Finalized code to generate all outputs and graphs


a) Download the whole folder. 
b) Rename the folder as PNAS_Code. 
c) Download the corresponding GTF and GAF files for this assembly (https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_003957555.1/) and place them in folders, Files for KEGG enrichments and WGCNA_data respectively. 
d) Open the project PNAS_Code.Rproj on Rstudio. 
e) For the WGCNA analysis, first run WGCNA_Gut1.r, WGCNA_Gut2.r ... , then WGNCA_KEGG_enrichment.r and finally WGNCA_KEGG_enrichments_Composite_Dot_plot_Figure_4.r 
f) For all other analyses, feel free to run in any which order.
